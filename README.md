# e-plantShopping

## Project Name

e-plantShopping

## Overview

e-plantShopping is a React-based plant shopping application that allows users to browse different plants and add their selected plants to a shopping cart. The application provides a simple and user-friendly interface for exploring and purchasing plants online.

## Repository

e-plantShopping

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* npm

## Features

* Browse available plants
* View plant information
* Add plants to the cart
* View cart items
* Navigate between the landing page, plants page, and cart
